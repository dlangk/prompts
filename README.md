# Prompts

A collection of reusable prompt templates for LLM workflows.

## Contents

| File | Description |
|------|-------------|
| `deep_research.md` | Generate structured research prompts for technical investigation |
| `style_extraction.md` | Extract writing style profiles for style transfer |
| `transcribe.md` | Clean up raw transcripts using clean verbatim conventions |

## Usage

Copy the relevant prompt template and customize the placeholders for your use case.
